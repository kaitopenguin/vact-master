## 🌟 Giới Thiệu Dự Án
**V-ACT Master** là ứng dụng web hiện đại được phát triển nhằm hiện thực hóa mục tiêu **bình đẳng giáo dục**, mang đến kho tài liệu, đề thi thử bấm giờ chuẩn hóa và hệ thống phương pháp tự học chất lượng cao hoàn toàn miễn phí cho tất cả học sinh và thí sinh ôn thi **Kỳ thi Đánh giá năng lực Đại học Quốc gia TP.HCM (V-ACT)** và **ĐHQGHN (HSA)**.

## 🚀 Các Tính Năng Nổi Bật

### 1. ⏱️ Hệ Thống Thi Thử Bấm Giờ Chuẩn Phòng Thi (150 Phút)
- **Chuẩn cấu trúc V-ACT mới nhất (120 câu / 150 phút)**:
  - **Phần 1: Sử dụng ngôn ngữ** (Tiếng Việt & Tiếng Anh).
  - **Phần 2: Toán học & Tư duy định lượng**.
  - **Phần 3: Tư duy logic, Phân tích số liệu & Suy luận khoa học**.
- **Chế độ thi linh hoạt**:
  - *Thi thử toàn phần*: Bấm giờ đếm ngược 150 phút, ma trận câu hỏi phân hóa, giao diện phiếu trắc nghiệm trực quan.
  - *Luyện nhanh chuyên đề*: Ôn sâu từng phân môn (Tiếng Việt, Tiếng Anh, Toán học, Logic, Số liệu) tùy theo quỹ thời gian của bạn.
- **Bảng phân tích năng lực chi tiết**:
  - Tự động quy đổi điểm chuẩn theo thang 1200 điểm của ĐHQG-HCM.
  - Biểu đồ năng lực từng môn giúp nhận diện chính xác điểm mạnh và lỗ hổng kiến thức.
  - Lời giải chi tiết từng câu, giải thích rõ vì sao đúng / vì sao sai.

### 2. 📖 Kho Sổ Tay Lý Thuyết & Chuyên Đề Cốt Lõi
- **Tiếng Việt**: Phân biệt từ Hán Việt dễ nhầm (sáp nhập vs sát nhập, yếu điểm vs khuyết điểm), nhận diện 6 phong cách chức năng ngôn ngữ, sửa lỗi câu sai ngữ pháp, nghệ thuật tu từ.
- **Tiếng Anh**: 5 chủ điểm ngữ pháp chiếm 90% đề thi (hòa hợp chủ vị, mệnh đề quan hệ rút gọn, đảo ngữ), kỹ thuật Skimming & Scanning bài đọc khoa học.
- **Toán học & Casio**: Khảo sát hàm số, bài toán tối ưu thực tế, xác suất biến cố đối, giải tích phân và thủ thuật bấm máy Casio 580VNX/880BTG trong 30 giây.
- **Tư duy Logic**: Phương pháp lập bảng ma trận (Matrix Table) giải bài toán sắp xếp vị trí, logic mệnh đề phản đảo và chân lý.
- **Phân tích Số liệu**: Công thức tốc độ tăng trưởng liên hoàn, tăng trưởng định gốc, tỷ trọng cơ cấu và mẹo đọc biểu đồ không bị bẫy.

## ⚡ Hướng Dẫn Chạy & Deploy Miễn Phí Lên Vercel

### Cách 1: Chạy Thử Trên Máy Tính (Local)
```bash
# Di chuyển vào thư mục dự án
cd vact-prep-app

# Cài đặt thư viện
npm install

# Khởi chạy máy chủ thử nghiệm
npm run dev
```
Mở trình duyệt tại `http://localhost:5173`.

---

### Cách 2: Triển Khai Miễn Phí Lên Vercel (2 Phút)

Dự án đã có sẵn file cấu hình `vercel.json`.

#### Cách A: Dùng Vercel CLI
```bash
# Cài Vercel CLI
npm install -g vercel

# Đăng nhập và triển khai
vercel

# Đưa lên bản Production chính thức
vercel --prod
```

#### Cách B: Kết nối qua GitHub
1. Tạo một repository mới trên GitHub (ví dụ: `vact-prep-app`).
2. Push toàn bộ mã nguồn lên GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: first release vact master"
   git branch -M main
   git remote add origin https://github.com/<tai-khoan-cua-ban>/vact-prep-app.git
   git push -u origin main
   ```
3. Truy cập [vercel.com](https://vercel.com) (đăng nhập bằng GitHub hoàn toàn miễn phí).
4. Bấm **"Add New Project"** > Chọn repository `vact-prep-app` > Bấm **"Deploy"**.
5. Vercel sẽ tự động build và cấp cho bạn một tên miền miễn phí dạng `https://vact-prep-app.vercel.app` có sẵn SSL bảo mật.
